## 公司概况

美团是中国领先的科技零售平台，以"零售+科技"战略践行"帮大家吃得更好，生活更好"的公司使命。

- **股票代码**：3690.HK
- **上市日期**：2018年9月20日
- **CEO/董事长**：王兴
- **总部**：北京
- **核心业务**：外卖+到店酒旅+闪购+社区团购+海外(Keeta)+AI助手(小美/小团)
