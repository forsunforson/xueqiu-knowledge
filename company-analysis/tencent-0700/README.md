## 公司概况

腾讯控股是中国最大、全球领先的互联网科技公司，构建了覆盖社交、游戏、数字内容、云服务、金融科技的完整生态。

- **股票代码**：0700.HK
- **上市日期**：2004年6月16日（港交所主板）
- **CEO/董事长**：马化腾
- **总部**：深圳
- **核心业务**：社交(微信/QQ) + 游戏(国内/国际) + 广告 + 金融科技 + 云服务 + AI
