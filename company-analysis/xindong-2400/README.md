## 公司概况

心动公司（XD Inc.）是中国领先的游戏开发商及运营商，旗下拥有 TapTap 游戏平台。

- **股票代码**：2400.HK
- **上市日期**：2019年12月12日
- **CEO/董事长**：黄一孟
- **总部**：上海
- **核心业务**：游戏研发与发行 + TapTap 平台
