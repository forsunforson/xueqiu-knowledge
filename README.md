## 数据格式

每条帖文 JSON：
```json
{
  "id": 1234567890,
  "created_at": "2026-07-02 13:18:35",
  "text": "帖文内容..."
}
```

## 采集方式

通过 Playwright + storage_state 调用雪球 `user_timeline.json` API，绕过 WAF。
